# Emergency Rescue Priority System

## About
A C programming project designed to manage emergency rescue requests and prioritize them according to emergency severity.

## Features
- Register rescue requests
- Categorize emergencies as Critical, High, or Normal
- Sort requests by priority
- Assign rescue teams
- Update request status
- Search requests by ID
- Display an emergency summary
- Save request details to a text file

## Technologies Used
- C Programming
- Structures and arrays
- String handling
- Bubble sort
- File handling

## How to Run
Compile:
`gcc rescue.c -o rescue`

Run on Windows:
`.\rescue.exe`

## Current Limitations
The current version does not reload saved requests after restarting or manage multiple teams' availability.
